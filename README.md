# OpeNext Foundation website

Static bilingual (中文 / English) site for [openextfoundation.org](https://openextfoundation.org), hosted on GitHub Pages.

- `index.html` — all page content (Chinese and English side by side, `lang="zh"` / `lang="en"`)
- `styles.css` — design (colors are defined at the top)
- `main.js` — language toggle, hub clocks, contact form
- `assets/` — logo files

The contact form is delivered by Web3Forms to the foundation inbox.
